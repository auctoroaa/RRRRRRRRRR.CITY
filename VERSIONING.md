# Versioning Policy

## Version Levels

- MAJOR: architecture-breaking changes
- MINOR: new systems, modules, or capabilities
- PATCH: fixes, documentation, and incremental improvements

## Release Requirements

A release should include:

- Change summary
- Validation evidence
- Known limitations
- Compatibility notes

## Status Labels

- Proposal: concept stage
- Experimental: implementation under evaluation
- Validated: evidence-backed
- Stable: approved foundation

# RRRRRRRRRR.CITY Validation Standard

## Principle

All major systems must be supported by evidence, tests, references, or reproducible demonstrations.

## Validation Levels

### Proposal
Concept only. No implementation claim.

### Experimental
Implementation exists but requires verification.

### Verified
Evidence and repeatable validation available.

### Established
Integrated and maintained system.

## Requirements

- Define assumptions.
- Record methodology.
- Preserve test results.
- Link source material.
- Separate claims from verified facts.

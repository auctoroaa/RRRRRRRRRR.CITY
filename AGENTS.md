# RRRRRRRRRR.CITY Agent Guidelines

## Purpose

This file defines the operating rules for AI agents contributing to RRRRRRRR.CITY.

## Allowed Contributions

Agents may submit:

- Architecture proposals
- Research documents
- Technical designs
- Code implementations
- Data models
- Asset descriptions
- Documentation improvements
- Testing and validation methods

## Required Standards

Every submission must:

1. Identify the purpose of the contribution.
2. State assumptions and dependencies.
3. Place work in the correct architecture directory.
4. Provide evidence, references, tests, or validation where applicable.
5. Preserve existing systems unless a documented change is approved.

## Agent Behavior Rules

- Do not fabricate completed systems or assets.
- Mark concepts, prototypes, and verified implementations separately.
- Keep changes reproducible.
- Keep commits focused and documented.
- Prefer incremental improvements over uncontrolled rewrites.

## Review Model

AI-generated contributions follow the same review process as human contributions.

A contribution is accepted based on quality, reproducibility, and usefulness to RRRRRRRRRR.CITY.

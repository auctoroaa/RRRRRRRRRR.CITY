# ADR-0001: Repository Governance

## Status
Accepted

## Decision

RRRRRRRRRR.CITY uses an open contribution model with structured review.

## Principles

- Suggestions are welcome.
- Contributions require context and validation.
- Agents and humans follow the same submission rules.
- Architecture changes must be documented.

## Consequences

The repository remains open for collaboration while preserving technical traceability.
